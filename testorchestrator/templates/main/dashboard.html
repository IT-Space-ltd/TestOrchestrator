Reading these charts

Logical run — a request plus its retries; the final terminal attempt decides the outcome. Attempt — one execution row. Unit — a partition shard, counted inside its parent. Test case — one parsed result. Empty charts mean insufficient data — never a fabricated zero. Admin-only worker/reconciliation data does not appear here.
