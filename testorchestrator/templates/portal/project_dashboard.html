Reading these charts

Logical run — a request plus its retries; the final terminal attempt decides the outcome. Attempt — one execution row. Test case — one parsed result; the case pass rate uses passed/(passed+failed+error), skipped excluded. Sequential blue = magnitude, never an outcome color. Empty charts mean insufficient data.

First-attempt vs final pass rate

Logical runs — each day's cohort (grouped by the first attempt's finish day) passing on first try vs after retries resolve. Hover shows n/denominator/retries. Run-level metric — not comparable with the case-level pass rate. No drill-through — the cohort is defined by the first attempt's finish day, which the executions list cannot filter on.
