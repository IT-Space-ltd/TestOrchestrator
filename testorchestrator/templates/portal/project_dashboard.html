Reading these charts

Logical run — a request plus its retries; the final terminal attempt decides the outcome. Attempt — one execution row. Test case — one parsed result; the case pass rate uses passed/(passed+failed+error), skipped excluded. Sequential blue = magnitude, never an outcome color. Empty charts mean insufficient data.
